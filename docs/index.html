ResQNet – Disaster Relief Coordination Platform

Connecting Resources. Coordinating Relief. Saving Lives.

ResQNet is an academic Internet Programming practical project designed to demonstrate practical concepts of HTML5 semantic elements, modern CSS3 layout and design systems, and Vanilla JavaScript DOM manipulation and localStorage persistence. It models a command center coordinating food, water, medical trauma kits, shelters, and emergency volunteers during flood, cyclone, landslide, and earthquake crises.

Technology Stack

Frontend: 100% Pure HTML5, CSS3, Vanilla JavaScript
Storage API: Browser localStorage (Zero backend needed)
Iconography: Font Awesome 6 (CDN-based)
Architecture: Single Page Application (SPA) with section swapping

Academic Viva Notes

No Frameworks: Zero React, Bootstrap, or Tailwind
CRUD: Built with native array methods (filter, map, push)
State Persistence: Survived across page reloads via JSON serialization
Export: Real-time browser CSV generation via Blob API
